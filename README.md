# ai
This repository contains my experiments, and projects related to Artificial Intelligence and Machine Learning.

## Programming for AI (M2) – CNNs & Transfer Learning on CIFAR-10

| Folder / file | Content |
|---|---|
| `Notebooks/utils.py` | shared code: data loaders, models (`Net`, `CustomCNN`, `get_resnet18`), training loop, evaluation, checkpoints, plots |
| `Notebooks/01_baseline.ipynb` | Task 1 – baseline CNN from scratch |
| `Notebooks/02_experiments.ipynb` | Task 2 – depth / kernel / stride / BN / optimizers / lr / schedulers / augmentation |
| `Notebooks/03_transfer_learning.ipynb` | Task 3 – ResNet-18 frozen vs fine-tuned vs scratch |
| `Notebooks/04_demo_inference.ipynb` | defense – load any checkpoint and test it on test mini-batches |
| `Checkpoints/` | best model of every run (`<run name>.pth`) |
| `results/` | training histories (`<run name>.json`), comparison tables (`.csv`) and `figures/` |
| `Report/main.tex` | IEEE report skeleton |
| `Presentation/outline.md` | slide plan |
| `Docs/defense_notes.md` | checklist, where to make live modifications, theory questions |

### Setup
```bash
pip install -r requirements.txt   # for an NVIDIA GPU, install torch first from https://pytorch.org
cd Notebooks
jupyter notebook
```
CIFAR-10 is downloaded automatically to `data/` on the first run.

### Training on Google Colab (free GPU)
The code comes from GitHub; the repository is cloned **into Google Drive** so that the checkpoints and results
written during training are kept (files on the Colab machine itself are deleted when the session ends).

**1. Clone the repository into Drive (one time only).** In a new, empty Colab notebook run:
```python
from google.colab import drive
drive.mount("/content/drive")
!git clone -b course-project https://github.com/MohammedZaiter/ai.git /content/drive/MyDrive/ai
```
The project is now in `My Drive/ai` (path in Colab: `/content/drive/MyDrive/ai`).

**2. Train.**
1. In Google Drive, open `My Drive/ai/Notebooks/01_baseline.ipynb` → *Open with → Google Colaboratory*.
2. **Runtime → Change runtime type → T4 GPU**.
3. **Runtime → Run all**. The first cell (`0. Google Colab setup`) mounts Drive (accept the permission popup)
   and moves into `Notebooks/`, so `import utils` and the relative paths work.
   Check that the output shows `Using device: cuda`.
4. Checkpoints and results are written to `My Drive/ai/Checkpoints` and `My Drive/ai/results`.
   If Colab disconnects, just run the notebook again: finished runs are skipped.
5. Same for `02_experiments.ipynb` and `03_transfer_learning.ipynb`.

**3. Get code updates.** Change the code locally, commit and push, then in Colab:
```python
!cd /content/drive/MyDrive/ai && git pull
```
Only edit the code in one place (locally) so that `git pull` has no conflicts. The notebooks executed on Colab
contain outputs; if `git pull` complains about them, run `git checkout -- Notebooks/<name>.ipynb` first
(the outputs will be regenerated by the next run).

**4. After training.** Download from Google Drive into the local project:
- `Checkpoints/` (`.pth` weights) – not pushed to GitHub (~400 MB)
- `results/` (histories, tables, figures)
- the executed `Notebooks/*.ipynb` (outputs are required in the submission)

Then run the notebooks locally with `TRAIN = False` (loading and inference work on CPU).

Colab already has PyTorch installed, nothing to `pip install`. Keep the browser tab open while training
(free Colab disconnects idle sessions).

### Run order
1. `01_baseline.ipynb` (~20 epochs, ~5 min on a GPU)
2. `02_experiments.ipynb` (20 runs, ~1.5–2 h on a Colab T4)
3. `03_transfer_learning.ipynb` (8 runs, ResNet-18 at 128x128, ~45 min–1.5 h on a Colab T4)
4. `04_demo_inference.ipynb`

Each notebook has a `TRAIN` flag in its settings cell: `True` trains (runs that are already saved are skipped), `False` only loads the saved checkpoints and histories so the notebook runs in a few seconds/minutes.
